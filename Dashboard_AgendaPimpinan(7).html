📋 Panduan Singkat SIDAP
1
Input Data di Spreadsheet
Isi kolom A sampai I (Tanggal, Waktu, Jenis, Nama, Lokasi, Peserta, PIC, Status, Keterangan)
2
Isi Kolom J (DIINPUT OLEH) Terakhir ⚡
Kolom ini adalah pemicu — begitu diisi, email & Google Calendar otomatis berjalan
3
Dashboard Update Otomatis
Dashboard refresh setiap 15 detik — data selalu terkini tanpa perlu refresh manual
4
Login Admin untuk Detail Lengkap
Buka menu "Agenda Hari Ini" → klik tombol login → masukkan username & password
5
Status yang Valid di Spreadsheet
AKAN DATANG → SEDANG BERLANGSUNG → SELESAI atau DIBATALKAN
